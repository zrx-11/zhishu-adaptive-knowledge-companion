# 外部课标知识图谱接入

zhishu 不内置任何外部知识图谱数据。当材料属于有公开课标的领域时，可以**可选**接入外部图谱，把书内依赖图升级为"书内 + 课标"双层。

## 可选数据源

| 项目 | 覆盖 | 节点/边 | 适合场景 |
|---|---|---|---|
| **cn-math-taxonomy** | 人教数学（小初高） | ~600 节点 / ~2800 边 / ~2800 题 | 中小学数学 |
| **Marble os-taxonomy** | 4–15 岁数学+英语 | 1591 节点 / 3221 边 | 小学到初中，有 assessmentPrompt |
| **K12-KGraph** | 人教数物化生 | 七类节点（概念/技能/实验...） | 中学理科全学科 |

按学段和学科选一个，不要同时接多个（节点 id 体系不同会冲突）。

## 什么时候接

- 材料是数学、物理、化学等对齐国家课标的教材/教辅。
- 学习者是在校学生，需要知道"这个知识点在整个课标里的位置"。
- 你希望诊断答错时，倒推能追到跨年级的根因（比如高中体积问题追到小学柱体锥体）。

以下情况**不接**，直接用纯书内模式：

- 材料是人文、社科、编程、商业等没有统一课标的领域。
- 概念名和课标术语对不上（强行匹配会教错）。
- 学习者目标是"读懂这本书"而非"备考/系统学一门课"。

## 接入步骤

### 1. 下载数据

从 cn-math-taxonomy 仓库拉取它的知识点 JSON（节点列表 + 先修边列表 + 诊断题）。不要把数据复制进 zhishu skill 目录——它是外部活跃项目，自己会更新。在每次生成任务时下载到 `_work/taxonomy/` 即可。

### 2. 匹配概念到外部节点

对 manifest 里每个 concept，尝试匹配：

- **精确匹配**：concept.title 和外部节点名完全一致。
- **同义词匹配**：常见别名表（如"导数"="变化率"="微商"），不要做语义模糊匹配。
- **匹配不上就留空**：`externalTaxonomyId` 字段留空，不要硬配。一个都匹配不上时，整个外部图谱功能静默降级。

### 3. 写入 manifest

匹配成功的概念，在 manifest 里加：

```json
{
  "id": "c01",
  "title": "导数",
  "externalTaxonomyId": "math.higher-derivative",
  "prerequisites": ["c00", "math.limit"]
}
```

`prerequisites` 里可以混入外部节点 id（带 `math.` 前缀），诊断倒推时会优先沿书内边，书内走到头了再沿外边继续。

### 4. 课标路径视图

在学习路径页（`__path__`）底部，如果有任何概念带了 `externalTaxonomyId`，渲染一段"课标位置"说明：

- 这个概念在课标中的前置节点链（沿外部先修边回溯到年级）。
- 后续节点链（学完这个会通向什么）。

这段是可选的，没有就不渲染。

## 边界

- **外部图谱只用于诊断倒推和位置视图**，不改变书内章节的拓扑学习顺序。书怎么讲是作者的事，课标只是参考。
- **AI 易错标注**：cn-math-taxonomy 有把"AI 会错的地方"单独标出的做法。生成内容时，对每个数值算例和测验题，强制自己算一遍/做一遍，算不通就换自拟题，并在页面注明"此例为自拟，非原书例题"。
- **版本对齐**：如果外部图谱更新了（先修边变了），重新跑一次匹配，不要拿旧缓存。
